# 工具状态标准化（Tool Status）

所有外部工具 / 数据源统一按四态管理。调用前先探针（DISCOVER → PROBE → 状态判定），按状态决定执行、降级或停止。

## 四态定义

| 状态 | 含义 | 处理 |
|---|---|---|
| AVAILABLE | 可用 | 正常执行 |
| DEGRADED | 降级可用（部分能力缺失或使用缓存数据） | 执行，并显式标注降级原因与数据时间 |
| UNAVAILABLE | 不可用 | 走降级链；无降级则停止并告知用户 |
| BLOCKED | 被合规 / 策略限制（非故障） | 不重试，使用现有资源或等待限制解除 |

## 探针流程

```
DISCOVER
   ↓
PROBE
   ↓
AVAILABLE?
   │
 ┌─┴───────────┐
 ↓             ↓
YES            NO
 ↓             ↓
EXECUTE      FALLBACK（降级链）
                ↓
          still unavailable?
                ↓
          STOP / 用户确认
```

## 降级规则

1. **降级必须显式标注**：记录 `primary_tool` 状态、`fallback_tool` 状态、`confidence`、数据时间。
2. **禁止伪装**：降级结果不得宣称完整模式（如降级检索后不得说"已全面检索"）。
3. **全部降级失败**：停止受影响流程，向用户说明原因，不用猜测结果顶替。
4. **医疗垂类**：检索类工具全部不可用 → `RESEARCH_UNAVAILABLE` → 停止，或经用户确认后进入降级生产模式（仍须标注限制）。

## BLOCKED 的常见场景

- **合规冷却**：数据源最低采集间隔未到（如丁香园热榜 5 分钟限制），触发返回 409——属常态，使用现有快照即可，不重试。
- **策略限制**：账号 / 平台不允许的操作（如未授权发布）。

## 专项源的 BLOCKED 传导（如 dxy 医疗热榜）

专项源（`dxy-crawler`，见 `tools/research/content-research.md#医疗垂类专项源dxy-crawler`）返回 409（合规冷却）时，按以下规则处理：

1. **BLOCKED ≠ 失败**：409 是合规保护，**禁止向上报「检索失败」**。
2. **自动改读快照**：切换 `source_type=snapshot`，读取最近快照，携带 `snapshot_time` 标注数据时间。
3. **报告措辞**：写「专项源在合规冷却中，已用 N 分钟前快照」，不写「检索失败 / 无数据」。
4. **不重试**：冷却未到不重试；机器人验证（"检测到异常流量"）同样等待数十分钟，不重试。
5. 快照也不存在（从未成功采集）→ 按 UNAVAILABLE 走降级链（dxy → bb-browser 公开检索 → RESEARCH_UNAVAILABLE 停止）。

## 与工具文档的关系

每个工具文档（`tools/*.md`）声明自己的探针方式、降级链与四态判定条件；本文件定义统一规则。工具在 `registry/tools.md` 登记时同步登记状态与降级链入口。
