# 质量门禁（Quality Gates）

所有产出在进入最终输出前必须通过门禁。任何关键门禁 FAIL 都不得进入 FINAL。门禁执行顺序与判定责任见下方。

## 门禁清单

| 门禁 | 检查内容 | 通过条件 | FAIL 处理 |
|---|---|---|---|
| 素材分级门禁 | 素材来源级别 | 无 D 级素材进入文案；C 级需授权 | 拦截，退回补素材 |
| 素材存在门禁 | `02_stories.md` 非空 | 至少 1 条适配的 ST-ID | 退回补采或请求用户提供素材 |
| 查重门禁 | 外部重复度 | <70% 通过；70-90% 重构；≥90% 拒绝 | 重构 / 拒绝 |
| 记忆防重复门禁 | 角度重复度 | 所选角度未在 `angles/` 高频使用 | 换未用 / 市场空白角度 |
| 事实门禁 | 事实可核实 | 关键事实有来源可溯源 | 标注假设或剔除 |
| 平台安全门禁 | 平台规则与医疗合规 | 无违规内容、无虚构病例、无编造医生身份 | 拦截修正 |
| 拟人化门禁 | AI 味程度 | 通过 humanize 检查 | 重写 |
| 账号契合门禁 | 账号定位匹配 | 符合 `account/style.md` | 调整表达 |

## 素材分级（A / B / C / D）

判定责任：story-collector 采集时标注级别；team-lead 在 Phase 3（选题决策）复核。

| 级别 | 来源 | 能否进最终文案 |
|---|---|---|
| A | 自有原创（访谈、亲历、授权素材） | 可以 |
| B | 公开报道（媒体署名、可核实） | 可以，标注来源 |
| C | UGC（论坛、社交平台） | 仅做趋势 / 选题参考；做素材需原始作者授权 |
| D | 无法核实的转述、二次改写 | **禁止进入文案** |

## 执行顺序

1. **Phase 1 后**：查重门禁（competitor-scout 输出 `01_scout.md` 时判定）。
2. **Phase 3（选题决策）**：素材存在门禁 + 素材分级门禁 + 记忆防重复门禁（team-lead 判定，写 `03_brief.md`）。
3. **Phase 6（汇编）**：全部门禁复查一次，含事实、平台安全、拟人化、账号契合，通过才写 `final_bundle.md`。
4. 任一关键门禁 FAIL → 返回对应阶段修正，修正后重新过门禁，不得跳过。

## 与工具状态的关系

门禁依赖的工具或数据源不可用时，按 `tool-status.md` 的降级规则处理；降级后的结论必须标注置信度与限制，门禁判定时按降级结论执行（如降级检索 → 查重门禁按"检索失败"处理，进风险确认节点）。
