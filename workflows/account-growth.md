# 工作流：账号养号增长（Account Growth）

> 触发条件：用户问「养号 / 涨粉 / 冷启动 / 从 0 到 1 / 矩阵起号」。
> 由 growth-specialist（步渐涨）输出三阶段方案，data-analyst（潘得清）辅助定义可量化指标。

## 三阶段总览

```
[阶段一] 冷启动（7–14 天）
   建立兴趣标签 → 养出「真人账号」画像
        │
        ▼
[阶段二] 内容测试（每日 1–2 篇）
   标题 / 封面 / 发布时间 / 关键词 A/B 测试
        │
        ▼
[阶段三] 数据优化
   按数据指标调整下一批内容方向
```

## 阶段一：冷启动（7–14 天）

目标：让平台算法给账号打上准确的兴趣标签，避免「新号权重低 + 无标签」的双重劣势。

每日动作清单：
- 浏览 20 分钟（垂类内容为主）
- 收藏 10 篇同行优质内容
- 评论 5 条（拟人化、有观点、不机械）
- 关注目标对标账号

## 阶段二：内容测试（每日 1–2 篇）

目标：用小批量高频发布，找出「标题 + 封面 + 时间 + 关键词」的最优组合。

测试矩阵：
| 维度 | 测试项 |
|------|--------|
| 标题 | 好奇型 / 数据型 / 冲突型 |
| 封面 | 大字报 / 场景图 / 对比图 |
| 发布时间 | 早 7–9 / 午 12–14 / 晚 19–23 |
| 关键词 | 核心词 + 长尾词组合 |

## 阶段三：数据优化

目标：用数据反哺下一批内容方向。

核心指标：
- 点赞率 = 点赞 / 曝光
- 收藏率 = 收藏 / 曝光（小红书权重最高）
- 评论率 = 评论 / 曝光
- 停留时间
- 涨粉率

调整规则：
- 收藏率高 → 加大「干货/方法论」内容占比
- 评论率高 → 强化「互动提问/争议话题」
- 涨粉率高 → 复制该篇的内容结构

## 风控提示（合规红线）

1. **拟人化操作**：所有动作带随机间隔，避免机械刷量。
2. **合理频率**：冷启动期不批量关注/评论，避免触发风控。
3. **规避黑产**：不刷粉、不刷赞、不使用非官方接口批量操作。
4. 小红书已发布《关于打击 AI 托管运营账号的治理公告》，自动化需评估封号风险。
