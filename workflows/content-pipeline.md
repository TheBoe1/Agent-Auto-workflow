# 工作流：内容生产流水线（Content Pipeline）

> 本工作流是 MCN-Agent-Studio 的核心，围绕「内容重复度确认」设计，编码成「方案一 / 方案二」两条分支。
> 触发条件：用户输入一个主题 / 大方向，要求产出小红书内容。

## 状态机总览

```
输入主题 / 大方向
        │
        ▼
[Phase 1] 趋势选题          trend-analyst（串行）
        │  输出：趋势判断、竞品对标、用户画像、竞争度
        ▼
[Phase 2] 全网查重          similarity-analyst（串行，核心）
        │  输出：{ duplicate, similarity, risk, reference[], verdict }
        ▼
   ┌────┴────────────────────────────────┐
   │ 有重复        无重复        检测失败  │
   ▼              ▼             ▼        │
【方案一】    【方案二·A】  【方案二·B】   │
   │              │             │        │
   ▼              │             ▼        │
[Phase 3] 重构    │        风险确认节点    │
 reframe-strategist │      等待用户确认    │
 蓝海搜索           │      A继续/B换主题/C参考
   │              │             │        │
   ▼              │             │        │
[Phase 3b] 二次查重│             │        │
 similarity-analyst│             │        │
   └──────┬───────┘             │        │
          ▼                     │        │
        [Phase 4] 内容生产 ◄────┘        │
        viral-copywriter + visual-designer（并行）
          │                              │
          ▼                              │
        [Phase 5] 数据复盘 data-analyst   │
          │                              │
          ▼                              │
        [Phase 6] 主理人汇编 → 输出稳定内容
```

## 阶段说明

### Phase 0：接单与需求澄清（主理人）
明确主题/方向、账号定位、目标用户、行业、是否附带已有文案；信息不全时补齐关键字段，缺省项需在最终产出中标注「假设值」。

### Phase 1：趋势选题（trend-analyst）
输入主题 + 账号定位 + 目标用户，输出赛道冷热判断、对标账号、用户画像、热点角度、竞争程度。

### Phase 2：全网查重（similarity-analyst，核心）
从标题、结构、关键词、语义四个维度比对，输出可量化结论：

```json
{
  "duplicate": true,
  "similarity": 0.87,
  "risk": "HIGH",
  "reference": [{"url": "", "title": "", "reason": "结构高度一致"}],
  "verdict": "重复，建议重构"
}
```

### 方案一：有重复 → 重构
1. **内容重构（reframe-strategist）**：拆解撞车点 → 定位重复根源 → 全网搜索「类似主题但未被充分覆盖的角度」（蓝海）→ 产出 3 个差异化重构方向。
2. **二次查重（similarity-analyst）**：对重构方案再次打分，≥90% 拒绝、70–90% 继续优化、<70% 通过。

### 方案二·A：无重复
跳过重构，直接进入 Phase 4 内容生产。

### 方案二·B：检测失败（风险确认节点）
搜索不可用 / 接口失败 / 无有效结果时，**禁止自动生产**，向用户输出风险说明并给出三选项，等待确认：
- **A 继续生成**：按「未完成查重、存在重复风险」标注后生产
- **B 重新输入主题**：换主题重走查重
- **C 人工提供参考**：用户提供参考内容做比对

### Phase 4：内容生产（并行）
- **viral-copywriter**：20 个标题（好奇/数据/冲突）+ 正文（黄金 3 秒开头 → 痛点 → 经历 → 方法论 → 行动建议 → 互动提问）。
- **visual-designer**：封面标题、视觉结构、配色、配图 prompt。

### Phase 5：数据复盘（data-analyst）
内容体检、最佳发布时间、预期指标（点赞率/收藏率/评论率）、复盘模板。

### Phase 6：主理人汇编
输出「可直接发布」的内容包：选题依据 + 查重结论 + 标题 + 正文 + 封面方案 + 发布建议，并标注风险点与假设值。

## 协作约束

1. 主理人负责编排与决策，**不代写任何成员的专业产出**。
2. 每阶段产出原文传递给下一阶段成员，所有信息流经主理人中转。
3. 未完成前序阶段，禁止跳到后续阶段。
