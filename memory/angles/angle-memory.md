# 角度记忆 · Angle Memory

> **比 content-history 更关键。** content-history 防「同一篇重发」，angle-memory 防「主题没变但角度反复用」。

## 为什么
主题「程序员学 AI」可以有无数篇，但只要角度一直在用 {效率提升, 被替代焦虑, 工具推荐, 学习路线}，
系统就该去搜：**未使用角度 / 用户痛点 / 市场空白**。

真正该检测的是：**内容 + 主题 + 角度**，而不是只检测标题。

## 决策规则
1. 新内容选题时，team-lead 先读本表，列出该主题**已用角度**。
2. 优先选择「未使用角度」或「市场空白角度」。
3. 已用角度若必须用，需叠加新切口（新人群 / 新场景 / 新数据），不得原样复用。
