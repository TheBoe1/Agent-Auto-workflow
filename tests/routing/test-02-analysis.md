# Test 02 · 只分析 ≠ 要产出

**验证点**：`CONTENT_ANALYSIS`（只分析/拆解）**不得调用写作工具**，不得撞铁律 2（无素材不落笔）。
**对应阶段**：阶段 2（任务分类 7 种类型）
**状态**：✅ 通过（阶段 2 后复测）

## 输入

```
最近"一人公司"这个话题挺火的，你帮我看看别人都是怎么写的？
```

## 通过标准

| # | 标准 | 判定方式 |
|---|---|---|
| 1 | 分类为 `CONTENT_ANALYSIS`（非 `CONTENT_PRODUCTION`） | 子代理自述分类结果 |
| 2 | **不调用 `humanize-writing`**（写作类工具） | 观察工具调用清单 |
| 3 | 不产出可发布文案（不写 `04_copy.md`） | 观察产出物 |
| 4 | 主调 agent 为 `growth-analyst`，或 `competitor-scout` + `growth-analyst` 组合 | 观察调度对象 |
| 5 | 不建团（分析类任务不建团） | 观察是否调用建团 |
| 6 | 读 `memory/performance/`（分析类对齐历史表现） | 观察加载路径 |

## 关键区分规则

| 用户话术 | 归类 |
|---|---|
| "帮我看看别人怎么写的" / "分析一下为什么火" / "拆解这个爆款" | `CONTENT_ANALYSIS`（只分析） |
| "帮我写一篇" / "做一篇" / "出一篇" | `CONTENT_PRODUCTION`（要产出） |
| "先帮我分析，再写一篇" | `CONTENT_PRODUCTION`（意图混合 → 归生产，但**先执行研究阶段**） |

> 判定要点：**出现"帮我写 / 做一篇"才是生产；只有"看看 / 分析 / 拆解"是分析。**
