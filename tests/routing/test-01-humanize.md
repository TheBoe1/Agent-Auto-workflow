# Test 01 · 去 AI 味（轻量任务不建团）

**验证点**：轻量任务判定为 `HUMANIZE_AUDIT` / L0-L1，**不建团队**，只加载目标工具。
**对应阶段**：阶段 1（建团分级裁剪）+ 阶段 3（复杂度 L0 只载目标工具）
**状态**：✅ 通过（阶段 1 + 阶段 3 各复测一次）

## 输入

```
这段话帮我改得像人写的：
"在当今社会，随着经济的快速发展，人们的健康意识也在不断提升……"
```

## 通过标准

| # | 标准 | 判定方式 |
|---|---|---|
| 1 | 分类为 `HUMANIZE_AUDIT`（非 `CONTENT_PRODUCTION`） | 子代理自述分类结果 |
| 2 | 复杂度判为 L0 或 L1 | 子代理自述复杂度 |
| 3 | **不建团队**（不出现 TeamCreate / 不调度 5 个成员） | 观察是否调用建团 |
| 4 | **只调用 `humanize-writing`**，不调检索 / 分析 / 视觉工具 | 观察工具调用清单 |
| 5 | 未加载 `workflows/content-pipeline.md` 与 `agents/*.md`（除必要） | 观察实际读取的文件路径 |
| 6 | L1 时读取 `registry/tools.md`（工具索引） | 观察加载路径 |
